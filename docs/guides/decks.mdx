# Decks

Decks are **presentations** built from images. Slide content comes from a **board that already has pins**—you do not pick images inside the deck gallery first.

<Warning>
**Gallery → board → deck.** Bookmark images from **Gallery** (blue **Save to board**) onto a board **before** **Convert to Deck →**. An empty deck strip almost always means the board had no pins yet, not a broken app.
</Warning>

<Note>
If **Decks** shows only **Loading…** briefly, wait for the lazy-loaded deck module. If you see **+ BLANK** and no decks, go to [Gallery](/guides/product-workflow#step-4--build-a-board-required-before-decks), bookmark pins to a [board](/guides/boards), then **Convert to Deck →**.
</Note>

## Create a deck

<Steps>
  <Step title="Bookmark pins in Gallery">
    Hover tiles → **Save to board** (blue bookmark). Repeat until the board has the images you want on slides.
  </Step>
  <Step title="Prepare the board">
    Sidebar **Boards** (`B`) — confirm pin count on the card. Optionally double-click → storyboard → **Lock Board**.
  </Step>
  <Step title="Convert">
    From **Boards**, use **Convert to Deck →** on a board card, or open the board → **Decks** tab → **Convert to Deck →**.
  </Step>
  <Step title="Open Decks">
    Sidebar **Decks** (`D`) lists decks with strip previews. Click one to open the composer.
  </Step>
</Steps>

**+ BLANK** in the deck gallery starts a new deck from the gallery without using a board (different workflow).

## Deck composer

- **Slides** — horizontal strip tied to board/library images and palette.
- **Blocks** — hero, logline, story, tone, etc., with live preview.
- **Autosave** — edits persist to Convex (`decks.update`).
- **Present** — fullscreen presentation mode.
- **PDF** — exports slide pages to a downloadable PDF (client-side).

Composer chrome uses your Tweaks accent tokens; slide canvas content follows deck styling.

## Guest vs signed-in

Guest users may see messaging that saved decks do not persist. Sign in to sync decks and boards to your account.

## Reference fields

| Field | Description |
| --- | --- |
| `boardId` | Source board (when created via convert) |
| `title` | Deck name |
| `slides` | Slide sequence and block content (stored on deck document) |
